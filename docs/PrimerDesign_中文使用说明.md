# PrimerDesign 中文使用说明

适用版本：`0.5.0`
运行环境：Windows x64，本机个人使用  
默认数据目录：`A:\CodexProject\prime_design`

## 1. 软件简介

PrimerDesign 是一套本地网页式批量引物设计软件。用户提交 1–20 条 multi-FASTA 序列并选择参考基因组后，软件自动完成：

1. 检查并规范化 FASTA；
2. 通过 SSH/Slurm 在服务器运行 Primer3；
3. 使用服务器上的 UCSC `isPcr` 检查成对引物可能产生的基因组产物；
4. 对无产物、多产物或非主染色体等可疑候选补充单引物 BLAT 诊断；
5. 生成可筛选的 HTML 报告和可直接用于 Excel 的 CSV/TSV 表格。

软件界面只监听本机 `127.0.0.1:43110`，不会作为公网网站开放。批量验证不调用 UCSC 公共网页；FASTA 和候选引物会通过已配置的 SSH 连接发送到计算服务器。

> Primer3、isPCR 和 BLAT 都是计算筛选工具。最终引物仍需结合实验目的、样本类型和实际 PCR/qPCR 实验确认。

## 2. 使用前准备

### 2.1 便携版文件

日常使用的程序为：

```text
A:\CodexProject\prime_design\dist\PrimerDesign-portable-win-x64\PrimerDesign.exe
```

便携目录必须保持完整，不能只把 `PrimerDesign.exe` 单独复制出来。便携版已经包含固定版本的 Node.js 和自包含启动器，不要求另外安装 Node.js 或 .NET。

### 2.2 服务器连接

自动计算依赖当前 Windows 用户的 OpenSSH 和 SSH 配置别名 `Fdu_imi`。使用前应确保：

- 电脑能够连接课题组服务器；
- `ssh Fdu_imi` 可以正常登录；
- 服务器上的 Slurm、Primer3、isPcr、BLAT 以及 `hs1`、`hg38`、`mm10` 索引已经部署；
- A 盘有足够可用空间。

打开软件后，可先在“系统检查”中点击：

- **刷新本地检查**：检查应用版本、A 盘目录、磁盘空间、SSH/SCP 和 Slurm 资源脚本；
- **检查服务器**：只读检查服务器连接、工具版本、部署清单和基因组索引。

服务器暂时离线不会阻止软件打开，但无法开始或完成远程设计与验证。

## 3. 启动与退出

### 3.1 启动

1. 双击 `PrimerDesign.exe`；
2. 程序在后台启动本地服务，不显示 CMD/PowerShell 黑色窗口；
3. 健康检查通过后，默认浏览器自动打开：

   ```text
   http://127.0.0.1:43110
   ```

重复双击不会创建第二个计算服务，而是复用已有实例并重新打开网页。

### 3.2 退出

使用网页右上角的 **退出软件**：

- 当前空闲：立即安全关闭；
- 当前有任务：软件会询问是否在任务完成并保存状态后自动退出。

直接关闭浏览器标签页不会停止后台服务。关闭网页后，可再次双击 `PrimerDesign.exe` 重新打开。

## 4. FASTA 输入要求

### 4.1 示例

```fasta
>Actb_mouse Actb transcript
ACCGCCGAGACCGCGTCCGCCCCGCGAGCACAGAGCCTCGCCTTTGCCGATCCGCC
>Gene_002 another target
ATGCGTACCGTAGCTAGCTAGCGGATCCGATCGATCGGCTAGCTAGCATCGATCGA
```

可以选择 `.fa`、`.fasta`、`.fna`、`.txt` 文件，也可以直接粘贴 FASTA 文本。

### 4.2 校验规则

| 项目 | 要求 |
|---|---|
| 记录数量 | 每批 1–20 条 |
| 文件大小 | 不超过 5 MiB |
| 最短序列 | 80 bp |
| FASTA 标题 | 每条序列前必须有以 `>` 开头的非空标题 |
| 内部 ID | 取标题的第一个空白分隔字段 |
| ID 字符 | 必须以字母或数字开头；只能包含字母、数字、点、下划线和连字符 |
| ID 长度 | 最长 80 个字符 |
| ID 唯一性 | 同一批次内不能重复 |
| 序列字符 | DNA/IUPAC：`A C G T R Y S W K M B D H V N` |
| RNA 字符 | `U` 自动转换成 `T` |
| 显示名称 | 预览后可修改，不能为空，最长 200 个字符 |

序列中不要加入空位符号 `-`、数字或其他注释字符。软件会一次列出发现的全部输入问题，不会静默忽略记录。

## 5. 选择参考基因组

每个网页批次只能选择一个统一参考基因组，必须由用户手动选择：

| assembly | 适用对象 | 说明 |
|---|---|---|
| `hs1` | 人 | T2T-CHM13 v2.0 完整基因组组装 |
| `hg38` | 人 | GRCh38/hg38 |
| `mm10` | 小鼠 | GRCm38/mm10 |

软件不会根据 FASTA 自动推断物种。参考基因组选择错误会直接导致错误的特异性结论。

## 6. Primer3 与 isPCR 参数

所有数值框都可以直接键盘输入、全选和粘贴。点击 **恢复默认参数** 可恢复下表默认值。

| 参数 | 默认值 | 可用范围/关系 | 含义 |
|---|---:|---|---|
| 候选引物对总数 | 5 | 1–20 的整数 | 每条 FASTA 最多返回的候选总数，包含排名第 1 的首选对 |
| Tm 目标 | 60°C | 有限数值 | Primer3 最适 Tm |
| Tm 容差 | ±5°C | 不得为负 | 默认允许 Tm 范围为 55–65°C |
| 引物长度 | 18 / 23 / 28 bp | 最小 ≤ 最适 ≤ 最大；最大不超过 35 bp | 最小、最适和最大引物长度 |
| 模板产物长度 | 80–1000 bp | 正整数；最小 ≤ 最大 | 在输入 FASTA 模板上设计的理论产物范围 |
| GC 含量 | 40–60% | 0–100%；最小 ≤ 最大 | 单条引物的 GC 硬约束 |
| isPCR 基因组产物最大长度 | 10,000 bp | 1,000–50,000 的整数 | 在基因组上搜索成对产物的最大长度；最小值固定为 0 bp |
| isPCR 并行任务数 | 4 | 4–8 的整数 | 候选按 round-robin 分片；提高并发会增加 NFS 与内存压力 |

提交后，实际参数会冻结到该批次的 `config.json`。断点重试继续使用原参数，不会被以后修改的网页默认值覆盖。

### 6.1 RNA/cDNA 模板的特别说明

如果输入的是 RNA 转录本或 cDNA 序列：

- **Primer3 模板产物长度**是在输入转录本序列上的距离；
- **isPCR 基因组产物长度**是在所选基因组上的距离，可能包含一个或多个内含子；
- 两个长度可能相差很大，这是正常现象；
- 若内含子使基因组片段超过 isPCR 上限，结果可能显示“无产物”；
- 跨剪接位点的引物也可能在基因组 isPCR 中无产物，但仍可能适用于 RT-PCR。

因此，“无基因组产物”不能自动解释为“引物一定特异”。需要结合外显子结构、转录本和实验目的判断。必要时可将 isPCR 上限从 10,000 bp 调高，但更大的搜索范围通常会增加运行时间。

## 7. 标准操作流程

### 第一步：输入序列

1. 填写“批次名称”；
2. 选择本批统一基因组；
3. 选择 FASTA 文件，或将内容粘贴到文本框；
4. 点击 **解析并预览**。

### 第二步：核对预览

预览表显示：

- 内部 ID；
- 可编辑的显示名称；
- 序列长度；
- 输入检查结果。

发现错误时先修改原 FASTA，再重新点击 **解析并预览**。

### 第三步：调整参数

按实验目的修改 Primer3 和 isPCR 参数。若不确定，可先保留默认设置：

```text
候选 5 对
Tm 60±5°C
引物长度 18/23/28 bp
模板产物 80–1000 bp
GC 40–60%
基因组 isPCR 上限 10,000 bp
```

### 第四步：开始运行

点击 **创建并开始设计**。软件自动执行：

```text
FASTA 严格复核与批次快照
        ↓
服务器 Slurm / Primer3 2.6.1 设计
        ↓
候选引物标准化与本地检查点
        ↓
服务器 UCSC isPcr 成对验证
        ↓
必要时运行单引物 BLAT 诊断
        ↓
下载原始结果并生成 HTML/CSV 报告
```

当前 Slurm 脚本申请 `16 CPU / 64 GB RAM`。isPCR 默认把候选 round-robin 分为 4 个 shard 并行执行，每个 shard 只加载一次基因组；网页可将并行数调为 4–8，实际并发不超过候选数。BLAT 仍在 isPCR 合并完成后单进程批量执行。

### 第五步：查看进度

进度区会显示：

- 批次状态；
- 正在校验数据库；
- 正在运行 isPCR，以及已完成候选数、总候选数和活动并发数；
- 正在 BLAT，以及需要复核的可疑候选数；
- 正在整理服务器结果、下载结果、校验下载结果或生成报告；
- Slurm 作业号、状态和已运行时间；
- 每条序列的阶段或错误。

网页每约 5 秒通过一次 SSH 同时读取 Slurm 和阶段进度；网页在后台时会降低本地状态轮询频率，不影响服务器作业继续运行。候选进度按完整 shard 跳动，例如 30 个候选、4 路并行时会按 `8/8/7/7` 完成，而不是每完成一对就变化。

## 8. 状态说明与断点重试

| 状态 | 含义 |
|---|---|
| `prepared` | 批次已经创建，尚未开始或等待继续 |
| `primer3_running` | 正在设计引物 |
| `validation_running` | 正在运行 isPCR/必要的 BLAT 验证 |
| `complete` | 所有可设计记录均完成验证 |
| `complete_with_warnings` | 批次完成，但部分记录无候选或存在警告 |
| `retryable_error` | 网络、SSH、Slurm 或文件传输等环节失败，可修复后重试 |

出现 `retryable_error` 时：

1. 不要删除批次；
2. 检查网络、SSH 和服务器状态；
3. 点击 **从断点重试** 或历史批次中的 **运行**；
4. 软件会复用已确认的设计、验证结果和缓存，不重复已完成阶段。

## 9. 查看和导出结果

任务结束后可以：

- 点击 **打开完整报告**：在新标签页打开 `report.html`；
- 点击 **页面内预览**：按需打开全屏报告层，主页滚动会锁定；Esc 或“关闭”可退出；
- 在完整报告中下载 `summary.csv`；
- 使用 **复制全部**、**复制筛选结果** 或 **复制选中行**，将 TSV 直接粘贴到 Excel。

完整报告支持按序列、assembly、验证结论和最大排名筛选；点击列标题可排序。
报告表格是唯一的纵向滚动区，表格顶部和底部横向滚动条双向同步，因此无需先滚到表格底部才能查看右侧列。

### 9.1 主要结果列

| 列名 | 含义 |
|---|---|
| `sequence_id` | FASTA 标题中的内部 ID |
| `display_name` | 预览时确认或修改的显示名称 |
| `input_template_length_bp` | 输入 FASTA 长度 |
| `assembly` | 本批参考基因组 |
| `candidate_id` | 软件生成的候选唯一 ID |
| `pair_rank` | Primer3 候选排名，1 为首选 |
| `forward_primer` / `reverse_primer` | 正反向引物，均以 5′→3′显示 |
| `forward_input_start_1based` / `end` | 正向引物在输入 FASTA 中的 1-based 闭区间 |
| `reverse_input_start_1based` / `end` | 反向引物在输入 FASTA 中的 1-based 闭区间，区间按模板坐标从小到大排列 |
| `forward_tm` / `reverse_tm` | 正反向引物 Tm |
| `forward_gc` / `reverse_gc` | 正反向引物 GC% |
| `product_length_design` | Primer3 在输入模板上的设计产物长度 |
| `score` | Primer3 pair penalty；通常越低越优 |
| `validation_classification` | 基因组 isPCR 验证结论 |
| `validation_product_count` | 当前参数下找到的基因组产物总数 |
| `genomic_product_lengths_bp` | 基因组产物长度；多位点时仅显示前 5 个 |
| `genomic_product_locations` | 基因组产物坐标；多位点时仅显示前 5 个 |
| `genomic_product_classes` | primary、alt/fix 或其他 contig 类型 |
| `validation_products` | 坐标、长度和 contig 类型的组合说明 |
| `warnings` | 模板坐标、工具或验证异常信息 |

坐标为空时，软件不会猜测位置，并会在 `warnings` 中标记“模板坐标未记录”或“模板坐标异常”。

### 9.2 验证结论

| 结论 | 含义 |
|---|---|
| 唯一产物 | 在所选 assembly 和当前 isPCR 参数下找到 1 个成对产物 |
| 多位点 | 找到 2 个或更多成对产物，存在非特异扩增风险 |
| 无产物 | 当前基因组、匹配规则和长度范围内未找到成对产物 |
| 需复核 | 命中 alt/fix、patch 或仅命中非主染色体等情况 |
| 验证失败 | 服务器、文件解析或验证过程失败，不能当作无产物 |
| 待验证 | 尚无对应 isPCR 结果 |

“唯一产物”只描述当前数据库和参数下的计算结果，不能排除未收录变异、样本差异、低相似结合或真实 PCR 条件造成的非特异扩增。

### 9.3 BLAT 数据

最终 HTML、CSV、复制表格和 `/results` 接口不显示 BLAT 专用字段。后台仍会按规则运行单引物 BLAT，用于解释无产物、多产物或可疑 contig 情况。原始 PSL、日志和哈希保存在批次 `raw` 目录中，供追溯使用。

BLAT 检查的是单条引物可能结合的位置；最终“产物数量”和“唯一产物/多位点”结论仍以成对 isPCR 为准。

## 10. 如何挑选候选引物

建议按以下顺序人工筛选：

1. 优先查看“唯一产物”，对“多位点”和“需复核”保持谨慎；
2. 核对目标基因组和产物坐标是否符合预期；
3. 比较正反向 Tm，避免两条引物 Tm 差异过大；
4. 检查 GC%、引物长度和模板产物长度是否适合实验；
5. 在其他条件相近时，优先考虑较低的 Primer3 penalty 和较高排名；
6. 对 RNA/cDNA 任务，同时检查转录本结构、外显子位置和基因组产物长度；
7. 关注 `warnings`；
8. 最终通过梯度 PCR、熔解曲线、凝胶电泳或测序等实验确认。

软件不会自动替用户决定最终引物。

## 11. 历史批次管理

主页“历史批次”提供：

- **查看**：打开已有静态报告；
- **查看进度**：查看运行中任务；
- **运行**：继续准备态或可重试批次；
- **重新验证**：保留 Primer3 候选，只按页面当前 isPCR 最大产物长度重新运行基因组验证；
- **删除**：经两次确认后，将整个本地批次目录移入 Windows 回收站。

重新验证前的 `config.json` 和 `ucsc-results.json` 会保存在：

```text
raw\validation-history\时间戳\
```

运行中的批次不能删除。回收站操作失败时，软件不会改为永久删除。

> 删除历史批次只处理该批次的本地目录，不会自动清除共享验证缓存或服务器上的远程运行目录。

## 13. 常见问题排查

### 13.1 双击 EXE 后没有打开网页

依次检查：

1. 再双击一次 EXE，软件可能已经在后台运行；
2. 手动访问 `http://127.0.0.1:43110`；
3. 检查 `A:\CodexProject\prime_design\logs` 中最新的 `.out.log` 和 `.err.log`；
4. 确认便携目录中的 `app`、`runtime`、`settings.json` 没有缺失；
5. 如需诊断，可运行项目根目录的 `Start-PrimerDesignApp.cmd`。

### 13.2 本地检查通过，但服务器检查失败

检查校园网/VPN、SSH 配置和服务器状态。可在 PowerShell 中只读测试：

```powershell
ssh Fdu_imi
```

不要在排障时随意修改或删除 SSH 私钥。

### 13.3 任务显示 `retryable_error`

先修复网络、SSH、Slurm 或磁盘问题，再点击“从断点重试”。不要为了重试重新创建同一批次，否则可能产生重复批次。

### 13.4 Primer3 没有返回候选

常见原因包括：

- 序列过短或低复杂度；
- Tm、GC 或长度约束过严；
- 要求的模板产物范围不适合当前序列；
- 模板含大量不确定碱基。

可逐步放宽参数后创建新批次，不建议一次同时大幅放宽所有约束。

### 13.5 本地结果与 UCSC 网页结果数量不同

比较时必须保持以下条件一致：

- assembly 完全相同；
- 正反向引物方向一致；
- 最大产物长度一致；
- 是否包含 alt/fix/random/unplaced contig 一致；
- UCSC 网页目标数据库和匹配规则一致。

本软件当前本地 isPCR 默认使用：

```text
minPerfect = 15
minGood = 15
flipReverse = false
基因组最大产物 = 网页本批设置值
```

如仍有差异，应查看批次中的 `queries.tsv`、BED、PSL、服务器工具版本和索引哈希，而不能只比较网页显示的一个数字。

### 13.6 Excel 打开 CSV 中文乱码

`summary.csv` 已包含 UTF-8 BOM。若旧版 Excel 仍显示异常，可使用“数据 → 自文本/CSV”并选择 UTF-8；也可以在报告中点击复制按钮，直接把 TSV 粘贴到 Excel。

### 13.7 软件看起来运行缓慢

运行时间主要受以下因素影响：

- FASTA 条数；
- 每条序列的候选引物对数；
- Slurm 排队；
- isPCR 最大产物长度；
- 可疑候选是否需要额外 BLAT；
- 网络传输速度。

报告不会自动加载到 iframe，点击“页面内预览”后才会加载完整表格。

## 14. 数据安全与使用限制

- 软件只在本机回环地址监听，不提供公网访问和多人账户；
- 输入序列会通过 SSH 上传到配置的课题组服务器计算；
- 不会将输入序列批量提交到 UCSC 公共网页；
- 删除本地批次不会自动删除远程服务器目录或共享验证缓存；
- 当前 UCSC 命令行工具按个人、学术或非商业场景使用；商业使用需另行核对授权；
- 引物设计结果不构成实验成功保证。

## 15. 推荐的最短操作清单

```text
□ 双击 PrimerDesign.exe
□ 刷新本地检查，必要时检查服务器
□ 选择或粘贴 1–20 条 multi-FASTA
□ 手动选择 hs1 / hg38 / mm10
□ 点击“解析并预览”，核对全部名称和长度
□ 保留默认参数或按实验目的修改
□ 点击“创建并开始设计”
□ 任务完成后优先筛选“唯一产物”
□ 对照模板位置、Tm、GC、penalty、基因组长度和坐标
□ 复制结果到 Excel 或下载 summary.csv
□ 通过实际 PCR/qPCR 实验确认最终引物
□ 使用“退出软件”安全关闭后台服务
```
